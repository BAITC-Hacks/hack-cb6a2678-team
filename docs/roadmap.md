## Открытые вопросы

| Вопрос | Почему важно | Кто выясняет |
|---|---|---|
| В каком часовом поясе «статистическое время» в датасете (UTC или UTC+5)? | Иначе факт и прогноз разъедутся на 5 ч, метрики — мусор | ML |
| Где лежит датасет и можно ли коммитить его в репозиторий? | Воспроизводимость для жюри | все / организаторы |
| Установленная мощность турбин (МВт)? | Чтобы показывать МВт·ч, а не только доли | все / организаторы |
| Задержка публикации прогонов ECMWF на Open-Meteo: сейчас 7 ч с запасом, точное значение не подтверждено | Слишком маленькая — утечка, слишком большая — чуть хуже прогноз | бэкенд |
| Как жюри будет запускать проект (есть ли у них GPU/ключи)? | Выбор размера LLM и режима по умолчанию | все / организаторы |
| Высота ступицы турбин | Пересчёт ветра на высоту | ML (можно оценить по данным) |
