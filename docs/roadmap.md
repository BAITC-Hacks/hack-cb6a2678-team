## Открытые вопросы

| Вопрос | Состояние |
|---|---|
| Часовой пояс «статистического времени» в датасете | Организаторы не указали. ML выбрала UTC+5 по ошибке на валидации (ноябрь–декабрь 2025); корреляция с ERA5 указывала на UTC+6 — `ML/TRAINING.md` |
| Можно ли коммитить датасет | Закоммичен в `ML/data/raw/` для воспроизводимости |
| Установленная мощность турбин (МВт) | Неизвестна — прогноз в долях номинала |
| Задержка публикации прогонов ECMWF на Open-Meteo | Взято 7 ч с запасом; точное значение не подтверждено |
| Есть ли у жюри GPU и Ollama | Неизвестно — README описывает Docker, режим без LLM и нативную Ollama |
| Высота ступицы турбин | Неизвестна — модель учитывает ветер на 10 и 100 м и сдвиг ветра как признаки |
